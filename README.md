# Eventory Card

Бесплатная local-first PWA-визитка для event-специалистов. Владелец собирает карточку на устройстве, публикует её по ссылке, показывает QR-код, получает обезличенную статистику, вопросы и модерирует видеоотзывы.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Проверка перед релизом:

```bash
npm run check
```

`npm test` проверяет автосохранение, шифрование резервной копии, аналитику, rate limit и ключевые UI-контракты. `npm run build` создаёт PWA в `dist/`.

## Архитектура и данные

- Черновик хранится в IndexedDB и зеркалируется в `localStorage`.
- Резервная копия шифруется AES-GCM; ключ выводится из пароля через PBKDF2-SHA256.
- `/api/card-publish` и `/api/card-get` проксируются в основной Eventory API.
- `/api/card-insight` хранит статистику и вопросы.
- `/api/card-review` создаёт приглашения, принимает и модерирует видеоотзывы.
- Публичные фото и видео нужно считать общедоступными после публикации/подтверждения.

## Обновление установленной PWA

Приложение устанавливается один раз. При запуске и возвращении из фона оно проверяет новую версию Service Worker. Если обновление найдено, появляется баннер и кнопка **«Обновить»** в шапке. Нажатие отправляет ожидающему Service Worker сообщение `SKIP_WAITING`; после смены контроллера приложение перезапускается на новой версии. Повторно устанавливать PWA не нужно.

Номер пользовательского релиза хранится в `src/app-version.js` и должен повышаться перед публикацией новой версии.

## Переменные Vercel

Для собственных serverless-функций обязательны:

- `UPSTASH_REDIS_REST_URL`
- `UPSTASH_REDIS_REST_TOKEN`
- Vercel Blob credentials, поддерживаемые `@vercel/blob` (`BLOB_READ_WRITE_TOKEN` либо настроенный OIDC-поток проекта)

Без Redis статистика и видеоотзывы возвращают `store_not_configured`. Без Blob запись визитки работает, но загрузка видео возвращает `video_storage_not_configured`.

## Релизный чек-лист

1. `npm run check` проходит без ошибок.
2. Preview deployment открыт на мобильной и узкой ширине, в консоли нет ошибок.
3. В Vercel настроены Redis и Blob для Preview/Production.
4. Проверены публикация и обновление тестовой визитки, публичная ссылка и QR.
5. На физическом iPhone в Safari проверены установка PWA, offline-повторный запуск, камера, микрофон и отправка видео.
6. Перед Production подтверждены юридические реквизиты и финальный текст политики конфиденциальности владельцем продукта.

## Границы безопасности

Ключ владельца даёт доступ к аналитике и модерации. Он не показывается на публичной странице, но входит в зашифрованную резервную копию. Не пересылайте файл и пароль одним каналом. Rate limit защищает публичные операции от массового злоупотребления, но не заменяет мониторинг Vercel/Upstash.
