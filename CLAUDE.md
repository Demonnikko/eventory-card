# Card (tadacard.ru) Claude Context

Короткий рабочий контекст для Claude Code и Antigravity.
Главное правило: одна задача за раз. Автономная проверка без ручных слэш-команд.

## Проект
- Local-first PWA-визитка для артистов и event-специалистов.
- Стек: Vanilla JS + Vite + IndexedDB/localStorage + чистый CSS (без фреймворков и без Tailwind).
- Основной фокус: мобильный Safari на iPhone, быстродействие, офлайн-режим через Service Worker (`vite-plugin-pwa`).

## Workflow автономной разработки

1. Понять задачу, найти целевой код (точечные правки в `src/` или `api/`).
2. Вносить изменения аккуратно, не трогая посторонние файлы.
3. **Автономная проверка (ОБЯЗАТЕЛЬНО перед каждым ответом)**:
   - Выполнить команду `npm run check` (прогоняет unit-тесты и делает продакшен-сборку `vite build`).
   - При правках мобильной вёрстки и адаптива — проверить консоль и отображение (через Playwright / эмуляцию iPhone).
   - **Если проверка или сборка падает**: НЕ сдавать задачу пользователю и НЕ требовать ввода команд. Самостоятельно читать лог ошибки, исправлять код и перезапускать `npm run check` до зелёного статуса.
4. При обновлении пользовательского интерфейса/функций:
   - Обновить версию релиза в `src/app-version.js`.
5. Деплой (только по подтверждению):
   - GitHub: `git push origin main` (Vercel обновится сам).
   - Сервер РФ: `bash scripts/deploy-ru.sh`.

## Ограничения
- Не добавлять лишние CSS-фреймворки (Tailwind и т.п.) — проект держится на чистом легковесном CSS.
- Учитывать зоны отступов iPhone (`env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`).
- Не ломать логику Service Worker и кэширования в `vite.config.js`.
